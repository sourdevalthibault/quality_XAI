# Qualité des explications d'un réseau de neurones

## Installation
Attention, il faut avoir une version de python en 3.11 pour utiliser la librairie quantus.
Je conseille donc de créer un nouvel environnement conda :
```bash
conda create -n quality_XAI python=3.11
conda activate quality_XAI
conda install pytorch torchvision captum matplotlib numpy pandas
pip install quantus
```
Sinon :
```bash
pip install torch torchvision captum quantus matplotlib numpy pandas
```
